# maxoff-site

The public marketing site for [MaxOff](https://maxoff.in), an operations app for small creative studios.

- `CLAUDE.md` has the rules, commands and Definition of Done.
- `docs/` has the brief, design system, sitemap, roadmap and progress log.

```sh
pnpm install
pnpm dev      # http://localhost:4321
pnpm check    # must pass before every commit
pnpm test     # Playwright smoke tests + axe
```
